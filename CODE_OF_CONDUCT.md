# Código de conducta

Queremos que usuarios y colaboradores puedan informar de problemas y participar con respeto, con independencia de su experiencia o procedencia.

Describe hechos y problemas concretos. Debate las ideas sin ataques personales; acepta correcciones y evita comentarios discriminatorios, amenazas, acoso, contenido sexual no solicitado o publicación de datos privados.

Los mantenedores pueden retirar contenido, cerrar conversaciones o limitar la participación ante incumplimientos. Explicarán la medida cuando hacerlo no exponga a las personas afectadas ni agrave la situación.

Para solicitar intervención, contacta con el mantenedor del repositorio. Si no hay un canal privado disponible, abre una incidencia pidiendo ese canal sin publicar datos personales ni detalles del incidente. Nadie debe divulgar información privada para poder recibir ayuda.

Estas normas se aplican a issues, pull requests y otros espacios oficiales del proyecto.

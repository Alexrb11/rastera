# Rastera 0.1.0-alpha.3

Alpha de escritorio con el logo de Rastera y primeros paquetes experimentales para Linux y macOS, además del ZIP Windows. Esta nota prepara la publicación; alpha.2 sigue disponible hasta que se publique alpha.3. La validación de equipos limpios, diferentes GPU y accesibilidad continúa pendiente. Los resultados de CI deben comprobarse en la ejecución correspondiente a esta release.

| Plataforma | Archivo | Alcance |
| --- | --- | --- |
| Windows 10/11 x64 | `rastera-0.1.0-alpha.3-windows-x64-msvc.zip` | Alpha inicial, runtime C estático; ejecutable sin firma de editor. |
| Linux x86-64 | `rastera-0.1.0-alpha.3-linux-x64.tar.gz` | Experimental; Ubuntu 22.04 como base, glibc ≥ 2.35, Vulkan, X11/Wayland, portal de archivos y Zenity. |
| macOS Apple Silicon | `rastera-0.1.0-alpha.3-macos-arm64.zip` | Experimental, macOS 13 mínimo declarado; firma ad-hoc sin Developer ID ni notarización. |
| macOS Intel | `rastera-0.1.0-alpha.3-macos-x64.zip` | Mismos límites, bundle nativo x64 separado. |

Cada archivo tiene una suma SHA-256 e incluye tutorial con capturas y fotografías de práctica, licencia MIT, avisos de dependencias y de la biblioteca estándar de Rust, e información de build. La suma permite comprobar integridad y no autentica al editor. Lee la guía de [Windows](../install-windows.md), [Linux](../install-linux.md) o [macOS](../install-macos.md). No necesitas Rust para usar un paquete.

Cambios:

- Logo aprobado e iconos en la ventana, ejecutable Windows, launcher Linux y bundle macOS.
- Linux permite instalación por usuario sin privilegios y registro opcional de Open With sin cambiar predeterminados.
- Atajos, menús y ayuda muestran Cmd en macOS y Ctrl en Windows/Linux.
- Catálogo y caché usan directorios del sistema; macOS conserva el catálogo antiguo cuando corresponde sin migrarlo automáticamente.
- CI y empaquetado preparan Windows, Linux, macOS arm64 y macOS x64 con metadatos y comprobaciones de arquitectura y dependencias.

Se conservan visor JPEG/PNG/WebP, cuadrícula virtualizada, favoritos y etiquetas, actualización automática de la carpeta y exportación de copias con revisión, cancelación y recuperación. Los originales permanecen en sus carpetas; exportar no reemplaza salidas existentes.

Límites: una carpeta sin recursión, hasta 10.000 entradas, imágenes SDR estáticas de 8 bits, sin RAW, HEIC ni animación. La conversión al perfil del monitor y la validación completa de accesibilidad están pendientes. Un renombrado externo no traslada organización. macOS no registra Finder Open With ni procesa eventos de documentos de Finder; abre imágenes desde su diálogo, arrastre o argumento de inicio. La matriz macOS 15 no valida todavía el mínimo macOS 13. El smoke gráfico Linux se limita al escritorio virtual y controlador registrados en el informe.

Para informar de errores, incluye versión, checksum, sistema y arquitectura, GPU/controlador, pasos y resultado. En Linux añade escritorio y X11/Wayland; en macOS, versión y chip/CPU. Evita fotografías privadas o rutas personales. Consulta `SECURITY.md` para incidencias de seguridad.
